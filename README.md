Entry for the make.fun bounty **Make the AI Judge Laugh (Office Life)**: one
funny single-line joke about office life, under 200 characters.

The program (`main.py`, Python 3.13, no dependencies) writes the joke to
`/output/entry.txt`:

> In my exit interview HR asked what would have kept me. I said 'this interview, three years ago.'

96 characters, plain ASCII. Run it with `python3 main.py`.
